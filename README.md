# S.T.A.L.K.E.R. GAMMA Artifact Guide

An independent field reference for GAMMA 0.9.5 artifacts, stats, tiers, and artifact-melter recipes.

## Data provenance
The artifact and recipe records in `data/` are derived from the GAMMA 0.9.5 exports published by [Stalker GAMMA Item Database](https://github.com/simonwdev/stalker-anomaly-gamma-db), which credits USADE by SaloEater and game data exports. See that project's [license](https://github.com/simonwdev/stalker-anomaly-gamma-db/blob/main/LICENSE) and acknowledgements. This repository uses a separately written interface and does not copy its application code or design.

Names are currently generated from internal item IDs because the exported JSON does not include localized display strings. Perk descriptions likewise remain keyed by their localization IDs until the corresponding text strings are sourced and verified.

## Run locally
Open `index.html` in a browser, or serve the folder with any static HTTP server.
